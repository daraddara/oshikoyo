# 実装済み機能カタログ (Features)

おしこよの全実装済み機能を分類別にまとめたリファレンスです。

## カレンダー

| 機能 | 概要 |
|:---|:---|
| 月別カレンダー表示 | 1〜2ヶ月分を縦・横レイアウトで表示 |
| 日本祝日自動表示 | 振替休日・特例措置を含む内蔵ロジックで計算。外部APIデータ取得済みの場合はそちらを優先 |
| 祝日データ同期 | Holidays JP API からの祝日データ手動同期。取得後はオフラインでも利用可能。未取得時は内蔵ロジックにフォールバック |
| 週の開始日設定 | 日曜始まり / 月曜始まりを選択可能 |
| 月ナビゲーション | 前月・翌月ボタン、今日ボタンでリセット |
| 2ヶ月表示トグル | ヘッダーのボタンで1ヶ月⇄2ヶ月を切り替え |
| 日付詳細ポップアップ | デスクトップ: ホバーポップアップ / モバイル: ボトムシート |

## 画像・メディア

### 登録方法

| 方法 | 対応環境 |
|:---|:---|
| ファイル選択 | 全環境 |
| フォルダ一括登録 | デスクトップ Chrome / Edge |
| クリップボード貼り付け | Chrome / Edge |
| ドラッグ＆ドロップ | デスクトップ |
| Web Share Target | Android Chrome のみ（他アプリの「共有」から直接送信） |

### 表示モード

| モード | 動作 |
|:---|:---|
| 手動（ピン留め） | 自動切替を停止し、特定の画像を固定表示。スワイプや矢印での手動切り替えは可能。ホームタブにピンアイコン表示 |
| ランダム | 設定間隔ごとにランダムに切り替え |
| サイクル | 登録順に順番に切り替え |

### 切り替え間隔

10秒 / 30秒 / 1分 / 10分 / 1時間 / 毎日 0:00 / 毎日 4:00 / 起動時のみ

手動モード（タイマー停止状態）を解除した際は、最後に使用していた間隔を自動復元。

### レイアウト

| レイアウト | 配置 |
|:---|:---|
| スマート（自動） | 縦長画像→左配置・横長画像→上配置を自動判定 |
| 上 / 下 / 左 / 右 | 手動固定 |
| 没入モード | 画像フルスクリーン、UIはマウスオーバー時のみ表示 |

### その他

| 機能 | 概要 |
|:---|:---|
| プレビューモーダル | 追加前に確認・タグ付け |
| ライトボックスビューアー | 拡大表示・削除・タグ編集 |
| スプリッター | 画像/カレンダーの境界をドラッグしてサイズ調整 |
| デフォルト画像 | 初回起動時に横長・縦長サンプル画像を自動登録 |

## テーマ（推しのデータセット）

推しをまとめた「テーマ」を作成し、カレンダー上部のバーで表示を切り替えられます。タグによる絞り込みを、より大きな単位に拡張した仕組みです。

| 機能 | 概要 |
|:---|:---|
| テーマの作成・編集・削除 | 名前・カラー・所属する推しを管理。テーマを削除しても推し本体は残る |
| 多対多の所属 | 1人の推しを複数テーマに所属させられる。推し編集画面のチェックボックスからも変更可能 |
| テーマ切替バー | カレンダー上部のチップバーで「すべて」／各テーマを切り替え。テーマ未登録時はバー自体が非表示 |
| 本日イベントバッジ | 選択中テーマ以外に本日の記念日がある場合、該当チップに 💡 を表示 |
| ティッカー連動 | テーマ選択中は、テーマ外の当月イベント件数をティッカーバーに表示 |
| テーマ単位のエクスポート | JSON（推し・記念日・タグ）または画像込み `.json.gz` を選択して書き出し |
| テーマ単位のインポート | 既存データを保持したままマージ。同名の推しは既存を再利用。同名テーマがある場合は「既存に統合」「別テーマとして追加」を選択 |
| テーマ別の使用量表示 | テーマ管理画面に画像枚数・合計容量・専有容量を表示 |
| デタッチ（端末から降ろす） | 画像込みファイルを書き出したうえで、そのテーマ**専有**の画像のみ端末から削除。ストレージ使用量を実際に減らせる |
| 旧グループからの自動移行 | 既存の「所属グループ」から初回起動時にテーマを自動生成し、旧フォーカスモードの選択状態も引き継ぐ |

### テーマ切替で絞り込まれる範囲

| 対象 | 挙動 |
|:---|:---|
| カレンダーの記念日表示 | テーマ所属推しのみ表示 |
| ティッカーバー | テーマ所属推しのイベントのみ表示（テーマ外は件数のみ） |
| 自動表示される画像 | テーマ所属推しの名前・タグに一致する画像を優先（一致0件なら全画像にフォールバック） |
| モバイル ホームの画像選択グリッド | 同上（一致0件なら全画像にフォールバック） |
| 推し管理一覧・画像管理画面 | **絞り込まない**（編集・削除の操作対象から漏れるのを防ぐため常に全件表示） |

### 容量対策：テーマのデタッチ

ブラウザのストレージ上限は**オリジン単位**で課されるため、データをテーマ別のデータベースに分割しても上限は増えません。加えて、画像はタグ経由の間接参照であり1枚が複数テーマに一致しうるため、物理分割すると共有画像が複製されて総使用量はむしろ増加します。

そこで、使用量を実際に減らす手段として**デタッチ**を提供しています。

| 用語 | 定義 |
|:---|:---|
| 専有画像 | そのテーマにのみ一致する画像。デタッチで削除される |
| 共有画像 | 複数テーマに一致する画像。デタッチでも**削除しない** |

デタッチの流れ:

1. テーマを画像込み `.json.gz` に書き出す
2. 書き出しに成功した場合のみ、専有画像を IndexedDB と `localImageMeta` / `localImageOrder` から削除
3. テーマ定義と推しの情報は残す（テキストデータのため容量に影響しないため）
4. 復帰は書き出したファイルのインポートで行い、同名テーマには「既存に統合」を選ぶ

専有画像が0枚の場合、「降ろす」ボタンは無効化されます。

## タグシステム

| 機能 | 概要 |
|:---|:---|
| 画像タグ | 各画像に複数タグを付与 |
| 推しタグ | 各推しに複数タグを付与 |
| タグオートコンプリート | 既存タグを候補表示 |
| 記念日×タグ連動 | 記念日に対応する推しのタグ付き画像を優先/専有表示 |
| 記念日表示モード | **優先**: 80%の確率でタグ一致画像 / **専有**: タグ一致画像のみ |
| タグフィルタリング | 画像管理画面でタグで絞り込み |
| タグマージ | インポート時に文字列照合で既存タグとマージ |

## ストレージ・バックアップ

### 画像自動圧縮

| 設定 | 内容 |
|:---|:---|
| 圧縮なし | 元ファイルのまま保存 |
| 標準（推奨） | 長辺最大2560px、JPEG品質88% |
| 積極的 | 長辺最大1920px、JPEG品質78% |

GIFは対象外。透過PNGは白背景に変換。

### バックアップ形式

| 形式 | 対象 | 復元モード |
|:---|:---|:---|
| フルバックアップ | 設定・推し・画像・タグ・メタデータ全て | **完全置換**（既存データ削除） |
| 画像+タグパッケージ | 画像とタグ情報のみ | **マージ**（既存データを保持して追加） |

### その他

- ストレージ使用量インジケーター（使用MB・上限MB・画像枚数）
- 登録済み画像の一括圧縮
- 全画像削除

## モバイル専用UI

### ボトムタブナビゲーション

| タブ | 内容 |
|:---|:---|
| ホーム | カレンダー・推し画像メイン画面。タップでポップオーバーを表示 |
| 画像ライブラリ | 登録画像のグリッド表示・管理 |
| 推し管理 | 推し一覧・追加・編集 |
| 設定 | 6つのサブパネルに整理された設定 |

### 再生モードポップオーバー

ホームタブをタップすると表示。表示モード（手動/ランダム/サイクル）と切り替え間隔を変更できます。手動モード中はホームタブにピンアイコンが表示され、手動での画像送りが可能です。

### 推し管理パネル

- 仮想スクロール（大量の推しでも高速）
- かな行グループラベル（あ/か/さ...行）
- 右端インデックスレール（行頭への素早いジャンプ）
- スクロールバブル（現在位置インジケーター）

### モバイル設定サブパネル

| パネル | 設定項目 |
|:---|:---|
| 全般 | 週の開始日、レイアウトリセット、祝日データ同期 |
| 記念日 | 画像表示モード（優先/専有） |
| 画像とストレージ | 圧縮設定・画像追加・ストレージ管理・バックアップ |
| イベント管理 | カスタムイベントタイプの追加・削除 |
| データ | フルバックアップ・復元 |
| アプリ情報 | バージョン確認・アップデート確認 |

### その他モバイル機能

- スワイプジェスチャーによる月移動
- ボトムシートによる日付詳細表示
- ティッカーバー（当日・直近の記念日をスクロール表示）
- 自動バー非表示（操作後一定時間でボトムバーを隠す）
